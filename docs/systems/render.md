# 渲染

低照度是永久设定。`lightMode.js` 已删，没有照明对比键。

`main.js`：`WebGPURenderer`，像素比上限 1.5，ACES，曝光 1.15。`ClusteredLighting(64, 32, 24, 16)`。半球光强度 0.55，月光方向光 0.3。`shanghai_bund_1k.hdr` 只做反射：场景 0.12，平板手部场景 0.35。

静态全局光照的实现仍在 `globalIllumination.js`（Three.js WebGPU `LightProbeGrid`），但 `main.js` 的 `USE_STATIC_GI` 现为 `false`：不创建探针、不采集、加载界面不再等待。改回 `true` 后，等 `buildCity().ready`（模型解析、材质替换及摆放完成），再在加载界面期间分批采集。探针体积覆盖封锁区前后各多 10 m，横向 20 m、高 6 m，底层位于桥面上方 0.3 m；5 × 3 × 29 个 L2 SH 探针、32 px cubemap、一次额外反弹。参数在 `GI`，整体强度 0.8。游戏开始前必须完成，进入游戏后只采样，不再更新；失败时退回原有光照，不阻塞开始。
- 采集用独立静态副本，几何和纹理共享，材质和灯光隔离；没有天空 / HDRI、雾、车辆、警灯、雨和调查全息。保留城市亮窗、招牌、灯带及静态表面的反弹，压低采集时的镜面 / 清漆高光，不把雾色烘进光照。
- 探针照亮主场景中已有的受光材质（桥面、混凝土、车辆等），与 GTAO、SSR 共存；独立的手 / 平板场景不受影响。导入楼仍保留 `MeshBasicNodeMaterial` 的顶点烘焙，不叠加探针光，避免双重照明。
- `USE_STATIC_GI` 为 `true` 时，开发态「测试 · 光源」里的「全局光照（静态探针）」和右上角「测试 · 静态光照」可切换；`window.__gi` 可查看 `status`、`progress`、`probes`。广告保持加载时的静态光照快照，轮播和警灯仍由原有实时点光表现，不重烘焙。

雾都在 `fog.js`，色值 `FOG_HEX`（`sky.js` 转导出）。可调参数是文件顶部的 `FOG` 表；开发态鼠标解锁时右下角有「测试 · 雾」面板，能实时拖动、开关两种雾，「复制参数」把当前值贴回 `FOG`。分辨率、采样次数、灯数上限是表下面的常量，改了要刷新。
- 距离雾 `distanceFog`（`scene.fogNode`）：远景雨霾密度随高度指数变薄，沿视线解析积分，上限 0.9；加桥下贴地低雾。两者都乘一层随风飘的 3D 噪声做浓淡起伏。
- 不参与雾的加法自发光（招牌标志、全息、大屏投影全息、巨楼编号、投影环）用 `fadeWithDistance` 只按同一雾量变暗，不叠雾色，避免雾色方框。分析线索、警戒线、低云不变暗。
- 体积雾 `createVolumetricFog`：后期里半分辨率沿视线采样到场景深度为止，再按深度联合双边上采样。底雾按雾密度（随高度变薄、带噪声团）累加 `FOG_HEX` 灰绿；灯光每帧从场景所有点光源读颜色、亮度、位置（最多 24 盏，最近优先），只在光源作用球内按角度均分采样，前向散射用 HG 相位。`userData.fogCone` 的灯（桥上路灯）按向下光锥算，`userData.fog = false` 的点光不参与。只加散射光不压暗，压暗交给距离雾，所以不写深度的全息不受影响。关掉时整个计算跳过。

天空两层，都在 `sky.js`：
- 天空盒 `sky_overcast.jpg`：Poly Haven `overcast_soil_puresky`（CC0），白天阴天全景只存上半球，按非 sRGB 读入后在 `backgroundNode` 里压成夜色。原图亮处当被霓虹从下方照亮的紫红云底，暗处是黑云；越近地平线城市光越强，视线高度 0.35 以下过渡到 `FOG_HEX`。横向随 `gameTime` 慢慢转动。固定采第 0 级 mip，否则经度接缝处有竖线。最亮处远低于 bloom 阈值。
- 低空碎云：240 m 高的噪声面片，不透明度上限 0.4，比天空盒飘得快，造前后层次。

MRT 有 `output`、`normal`、`metalrough`、`keep`。`keep = 1` 的像素在分析模式保留原色。

烟雾粒子都在 `smoke.js`：车头浓烟（深灰，底部随车头火光闪橙）、火星（加法，亮于 bloom 阈值）、桥面风雾（相机前后 70 m 循环）、桥下蒸汽（`VENTS` 九个口，升过桥面才看得见）。全是 `Sprite.count` 实例化面片，位置由 `instanceIndex` 和 `gameTime` 在着色器里算，没有 CPU 逐粒子更新，冻结时一起停。风向用 `rain.js` 的 `WIND`。
- 粒子在独立场景 `smoke.scene`，`main.js` 用半分辨率 `pass` 渲染后按 alpha 叠回。不能放进主场景：MRT 里透明物体会不混合地覆盖 `normal` / `metalrough`，烟雾面片会在路面反射上抠出方框。
- 遮挡和软边靠采样主场景深度（`soft()`），共用 `scene.fogNode`。
- 这一遍常在 bloom 等效果"重置渲染状态"（清屏 alpha = 1）时被触发，所以 `smoke.scene.onBeforeRender` 里自己把清屏 alpha 设 0。漏掉的话叠回时整屏场景被吃掉。
- 开发态光源面板有「车头烟 / 火星」「雾气 / 蒸汽」两个开关。

顺序：SSR → 烟雾粒子 → 体积雾 → 平板虚化并叠 `uiScene`（手和终端不进雾）→ bloom（强度 0.5，阈值 1.3）→ 分析去饱和 → 调色 → SMAA、色差、暗角、胶片。阈值 1.3 让地面高光不出晕。护栏霓虹 `0x20f0ff` 再乘 0.9，故意留在阈值下。路面金属度在 `bridge.js` 里 `mix(0.15, 0.5)`。近处屏幕点光强度 100。

雨是 `rain.js` 里跟随相机的 6000 根线段。桥和招牌用 `mergeStatic` 按材质合并。

导入楼不要改成实时受光还同时靠顶点色烘焙。无头 `--disable-gpu` 不能验收画面。
