# 现场调查

剧情依据 [../Story/事故之前-序章.md](../Story/事故之前-序章.md)，现网接到对象索引收起后的独白，然后进入结局动画。

开场在 `intro.js`：高角度跟车约 7 秒。加载黑幕完全揭开前 2 秒播派单通话（`beginOpening`）。正面看停车约 4 秒，停稳后再留 0.3 秒，切回驾驶座并播完整下车。下车结束后平板自动举起显示系统初判，TAB 或空格收起后交还控制，陈墨内心独白「OK，开始吧，看看有什么新发现。」（`LINES.start1`）。黑边出现时字幕抬到黑边上方。开发态空格跳过整段，正式包不能跳过。模式在 `state.js`：`explore`、`recon`（黑梦）、`report`（平板举起看报告 / 接入画面）、`ending`（报告 02 归档 / 报告 03 移交后的假结局）、`insert`（撬门、插卡、拿根钥的镜头接管）、`death`（结局）。文案、轮次、报告、台词都在 `clues.js`。HUD、字幕、黑边在 `ui.js`。回放在 `recon.js`。平板在 `tablet.js`。结局在 `finale.js`。可暂停的动画读 `clock.js` 的 `gameTime`，不用 TSL `time`。`uiTime` 不停。

## 轮次

已录好的 65 条英文配音仍按原句绑定（含两个假结局）。中文原稿和录音逐字相同的句子继续走 FMOD；改写过的句子只显示新字幕，用原来的阅读时长，不把旧录音套上去。语言按钮只切字幕和界面，两种语言都沿用相同的英文配音；英文字幕使用 `en.js` 的译稿，措辞可能与录音略有不同。`voiceMap.js` 按已发布录音的 `VOICE_LINES.source` 匹配中文原句，再通过 `bi()` 的 `RAW` 取回原对象，不随语言或 Proxy 身份变化。`ui.say` 按 FMOD 真实结束状态逐句推进；暂停会停声并冻结句间间隔，跳过或被新对话中断时停止旧声，返回 `false` 以取消旧剧情续接。新版稿和旧录音不一致的句子只显示字幕，原音频仍保留供试听。音色、来源与混音见 [英文配音](../voice-en.md)。

## 黑梦

四次黑梦都是 4 秒。没有事件记录，也没有时间跳跃。空格暂停，滚轮擦时间，Q 离开。每一轮的完成条件都是：该轮 `key` 分析点全部分析，完成后自动出报告。进度条黄块只来自带 `t` 的分析点，宽度是该点前后各 0.25 秒，和分析菱形出现的时间一致。分析完算已记录。

分析点按住 E，开始时自动暂停。菱形在回放时间进入该点的 `t ± 0.25` 秒时出现（不论远近，标距离），走到 8 m 内才能瞄准。第 1 轮是 A 车转向（`p1turn`，1.4 秒）。第 2 轮是 A 车前轮（`p2gap`，1.15 秒）和黄色车辆（`p2car`，1.4 秒）。第 3 轮是 A 车接管（`p3override`，1.1 秒）和零号保障通道（`p3halo`，1.4 秒）。每轮都要全部分析。结果进平板「线索」页，标「梦」。

黑梦 3 只能露出接管和零号保障，不能露出报告早于事故、零号保障临时写入、黄车也被接管，这三件留给第 4 轮。`p3halo` 故意写「通道全程存在」。文案里统一叫「让行道 / 让行通道」，和路面标字「让行区」对应，不再叫白圈或边界。零号保障在 `recon.js` 的 `buildP0` 里画成黄车的「保障通道」，不做光环：沿黄车路线从车尾往前铺约 20 m、一条车道宽的路面保留区（冷灰白虚线边、极淡填充、远端渐隐，虚线按路线里程固定在路面上），车头前方贴地印「零号保障 / 让行区」，亮度低于车辆全息体。`ROUNDS[n].actors.p0` 是出现时刻：黑梦 3 为 0（看起来一直都有），黑梦 4 为 0.8，写入时不闪烁，通道在 0.3 秒内从车尾铺到远端，边线短暂提亮，标字等通道铺过去后再淡入。

每轮蓝色人影都按惯性甩出：2.5 秒车开始急减速，人保持此刻车速前冲；撞上仪表台和前挡时水平速度降到 65%，被向上、向外弹开，腿被绊住开始向前翻滚；之后自由抛体加翻滚，四肢由程序化姿势甩开并乱摆，越过护栏缺口，掉到桥面下 12 m 后隐藏。轨迹在加载时积分成表，回放按时间查表（`recon.js` 的 `LURCH_T` `HIT0` `HIT1` `KEEP` `POP_VY` `POP_OUT` `PITCH_W` 和 `LIMBS`）。桥面没有尸体和血迹。

车全息 `shell: true`，强度 0.55。干净车壳在揉皱车头前克隆。左前轮平放在桥面。

## 平板

页签：线索 / 报告。报告页左侧列初判和已生成的复核报告，W / S 或点击切换。线索页只直接列本轮的线索（解锁后的原始记录算第 4 轮，`showRound`）；之前轮次收进列表下方的「之前的线索（n）」折叠项，点击或按 E 展开，每次举起平板时收起。车载数据没有现场位置，只出现在平板里；`locked` 条目显示为权限不足。

插卡时平板播放 `CARD_HACK` 的逐行接入画面和进度条，完成后停在「接管记录」线索。

左手握着平板左边缘：边缘卡在虎口，四指在背面托着，拇指压在正面边框上，前臂从画面左下伸进来；举起、收起（往左下放）、晃动都跟着平板一起动，掉在地上时没有手。手是 `tablet-hand.glb`，只有一个单帧握姿 `Grip_Tablet`。网格来自源模型的左手（`art/fps_arm_left.blend`，`tools/blender/fps_arm_left.py`），直接握左边缘，游戏里不再镜像。glTF 坐标就是平板 holder 的本地坐标，直接挂在 holder 下。屏幕透明，背面四指隔着玻璃被压暗、偏冷，拇指在正面挡住界面（玻璃和界面开了深度测试）。改握法：调 `tools/blender/build_tablet_hand.py` 开头的参数，后台跑一遍会重新导出并渲染预览。平板举起后的姿态 `SHOWN` 要和脚本里的 `SHOWN_POS` / `SHOWN_ROT` 一致。

## 电子杂志

世界观补充，不计入线索和任务（`magazine.js`）。一本《城脉 / METRO PULSE》电子杂志躺在事故车左侧（朝护栏一侧）车门后方的玻璃渣里（`GROUND_POS`，约车本地 x -1.2、z -1.5，离脱落的左前轮约 0.8 m），像是撞击时从碎掉的车窗滑出来的；屏幕朝上，封面一直在动（俯瞰高架：车流整齐，只有中间一条金色车道空着）。平时待机调暗（`GLOW_DIM`），每隔 9～16 秒像收到推送一样亮起约 2 秒（`GLOW_PING`，不过辉光阈值），顶部滑下「城脉 · 新一期已送达 / 零号保障：世界为你让路。」横幅；偶尔闪一下。只在探索中可拾起：准星对准、眼睛到杂志 ≤ 3 m，四角框只显示「E」，名字「电子杂志 · 拾起」；瞄准线索、车门、接口、根钥时优先它们。

按 E：扫描枪收起，镜头下蹲低头（视线追着杂志），杂志先贴地往脚边滑一下、翻起离地，再带着重量感到镜头前（1.3 秒），背景虚化、轻微压暗。阅读期间 `controls.enabled = false`：不能走动、视角固定，鼠标移动不响应；A / D、← / →、滚轮翻页（滑动 + 故障条）；E 放下（1.05 秒）：镜头再蹲下，杂志一边先着地再放平，落在原位，朝向按放下时的视线方向（顶边朝外，带一点随机），不转回原来的角度；回到封面，恢复操作。TAB、Q、R 等都不响应。期间切换模式（剧情推进、跳关）会直接放回地上，镜头回到站姿。

在地上时杂志属于主场景（受光、雾、屏幕反射）；拾起期间挪进平板的 `uiScene`，不会插进别的物体。加载界面期间 `warm` 把它轮流放进 `uiScene`，提前编译手持状态的材质。4 页内容（封面、枢核年度报告、简讯 + 莲华诊所广告、零号保障整版广告）都在画布上程序绘制，中英文随语言切换；广告图是 `public/assets/gen/mag_lotus.jpg`（来自 `art/ads_src/v02.png`）。改文案改 `drawCover` / `drawFeature` / `drawBriefs` / `drawAd`。

「现场调查」在探索和黑梦显示，平板举起、报告、过场时隐藏。左侧组在屏幕高度 25% 处，缩放 1.5。这是桌面布局，不另做窄屏。
